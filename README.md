# Chinese-Home-Garden-Design

松阳家庭花园的可交互 3D 页面，按 CAD 平面图（`ww(1).pdf`）1:1 建模，单位为米。

## 直接使用

成品是一个独立文件：**`dist/garden-3d.html`**（约 0.9 MB）。

- three.js 引擎、贴图和布局数据全部内联在文件里，不访问任何外网，国内服务器或离线都能打开。
- 放到自己的服务器上：把这个文件上传，用浏览器访问即可（任何静态托管都行，比如 Nginx、对象存储）。
- 电脑上双击用浏览器打开；手机上用"在浏览器中打开"。

### 操作

| 模式 | 电脑 | 手机 |
|---|---|---|
| 鸟瞰 | 左键旋转 · 滚轮缩放 · 右键平移 | 单指旋转 · 双指缩放/平移 |
| 漫步（人眼 1.6 m） | W/A/S/D 或方向键走 · 按住鼠标拖动转头 · Shift 加速 | 左下摇杆走 · 拖动屏幕转头 |

底部按钮是预设视点（全景鸟瞰、俯视对照、北门进入、茶座、亭中望水、花架下、南花园小径、南门……）。
右上"设置"里可以调时间（6:00–20:00，太阳方位按松阳纬度计算，傍晚景观灯会亮）、开关标注/植物/微风、
**叠加原平面图**（把 CAD 线稿铺在地面上，用来核对位置），以及切换画质（老手机选"流畅"，会关掉水面实时倒影）。

URL 参数：`?v=编号` 指定初始视点，`?t=17.5` 指定时间，`?q=low` 流畅画质。

## 已确认的设计前提

- 主屋：现代三层小楼，L 形（平面图中填充图案区域，填充本身忽略）。
- 东侧 3 个方形符号 = 景观灯柱；竖条纹带 = 木栈道。
- 场地全部平整，无高差；东侧水泥路与南北两扇大门都属自家院子。
- 围墙：矮墙（0.6 m 白墙 + 深灰压顶）+ 内侧绿篱（约 1.2 m）。
- 南段以图上实际画的长度为准（实测各段与标注误差在 1–2% 内）。
- 西南角原图只是示意，3D 中按"早园竹 + 茶树（松阳茶乡）+ 景石"设计。
- 植物按浙西南本地常见品种配置：桂花、香樟、红枫/鸡爪槭、山茶、杨梅、柚子、紫薇、棕榈、苏铁、棕竹、绣球、杜鹃、栀子、红叶石楠球、紫藤、睡莲、菖蒲等。

## 目录

```
data/layout.json        从 PDF 提取的布局（米；x 向东，z 向南，原点为地块西北角）
tools/extract_layout.py PDF → layout.json（比例 68.88 mm/pt，由 23000 / 65800 mm 两条边标定）
tools/plan_overlay.py   PDF → 平面图叠加用的透明 PNG
tools/pdfgeom.py        读取 PDF 矢量线条的公用函数
web/src/                3D 场景源码（three.js）
web/build.mjs           打包成单个 HTML
web/shot.cjs            用无头 Chromium 截图自检
dist/garden-3d.html     成品
```

## 修改与重新生成

```bash
# 1) 若平面图有更新：把 PDF 放到 plan/ww1.pdf（或用 GARDEN_PDF 指定路径）
pip install pymupdf pillow
python3 tools/extract_layout.py
python3 tools/plan_overlay.py

# 2) 打包
cd web && npm install && npm run build      # 输出 dist/garden-3d.html
```

植物的位置和种类在 `tools/extract_layout.py` 的 `PLANTS` 列表里（原图的植物符号被炸开成散线，
所以是逐个读坐标录入的）；汀步、木条、景石、灌木圆圈等是程序自动识别的。
建筑高度、材质、植物形态在 `web/src/structures.js` 和 `web/src/plants.js`。
